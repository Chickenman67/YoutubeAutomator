# YouTube Automation System

An automated pipeline for generating daily educational video content with trending and evergreen topics, producing mid-form videos with extracted Shorts for multi-platform distribution.

## Language

**Video**:
A complete produced video file (5-10 minutes) ready for upload, consisting of script, voiceover, visuals, and metadata.
_Avoid_: Content, media file

**Short**:
A 60-90 second vertical video extracted from a single scene of a mid-form Video, optimized for YouTube Shorts, TikTok, and other short-form platforms.
_Avoid_: Clip, snippet, short-form

**Scene**:
A discrete segment of a Video covering one fact or point, with its own script section, voiceover, and visuals. The atomic unit that becomes a Short.
_Avoid_: Section, segment, chapter

**Script**:
The written narration text for a Video, structured as multiple Scenes, generated by LLM with humanized writing style and fact-checking validation.
_Avoid_: Transcript, copy, text

**Trending Topic**:
A subject sourced from Wikipedia trending pages or Reddit, filtered by engagement threshold and explainability score, used for 70% of daily Video production.
_Avoid_: Viral topic, hot topic

**Evergreen Topic**:
A curated subject from the topic pool JSON file, used for 30% of daily Video production, with 90-day rotation to prevent repetition.
_Avoid_: Curated topic, static topic

**Topic Pool**:
A JSON file containing categorized Evergreen Topics with usage timestamps, manually editable by the user.
_Avoid_: Topic list, topic database

**Queue**:
The folder-based state management system for Videos: `pending_review/` → `approved/` → `uploaded/`.
_Avoid_: Pipeline, workflow

**Review Dashboard**:
A local HTML interface for previewing pending Videos, displaying script, metadata, fact-check results, and approve/reject controls.
_Avoid_: Admin panel, interface

**Fact-Check**:
Wikipedia API validation of factual claims extracted from a Script, producing confidence scores and flagging low-confidence claims for user review.
_Avoid_: Validation, verification

**Explainability Score**:
LLM-based assessment of whether a Trending Topic can be explained in 5-10 minutes with verifiable facts, used to filter out unsuitable topics.
_Avoid_: Educational score, quality score

**Metadata**:
Auto-generated YouTube video information: title, description, tags, category, optimized for SEO and discoverability.
_Avoid_: Video info, details
